# ABP3 – JavaScript Asíncrono (Callbacks)

Este mini‑proyecto implementa los dos pasos del enunciado:
1) Una función principal que saluda y luego ejecuta un callback que pregunta por café.
2) La función `operaciones(a,b,minora,potencias)` con callbacks anónimos que imprimen frases adaptables.

## Cómo probar
1. Abre `index.html` en tu navegador.
2. Abre la consola (F12 → pestaña *Console*) para ver los mensajes.
3. Usa los botones de la página para ejecutar cada paso.
4. Cambia los valores de **a** y **b** y vuelve a ejecutar; las frases se adaptarán automáticamente.
