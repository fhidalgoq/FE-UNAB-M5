# 🏥 Gestión de Pacientes (JavaScript ES5 + Bootstrap 5.3)

Aplicación web sencilla para mostrar y buscar pacientes, desarrollada con **JavaScript Vanilla (ES5)** y **Bootstrap 5.3**.  
Permite listar todos los pacientes o buscar por nombre, mostrando los resultados en una tabla estilizada.

## 🚀 Características
- Mostrar todos los pacientes registrados.
- Buscar paciente por nombre (coincidencia exacta).
- Interfaz limpia y responsive gracias a Bootstrap.
- Código en JavaScript ES5, sin dependencias adicionales.
